# Contributing

Thanks for your interest in contributing.

This repository is intended to be a practical, architecture-first resource for enterprise retrieval and workflow-safe AI integration patterns. Contributions should make the repository clearer, more reusable, and more useful for teams building real operational systems.

## Good contributions

- improve architecture explanations
- add implementation-agnostic examples
- clarify system boundaries and failure cases
- expand policy and escalation patterns
- improve diagrams, documentation, and ADRs

## Out of scope

- vendor-specific sales material
- branded customer examples
- private implementation details
- example code that exposes sensitive operational patterns without explanation

## Contribution guidelines

1. Start with an issue when the change is non-trivial.
2. Keep examples public-safe and anonymized.
3. Prefer clarity over cleverness.
4. Explain architectural tradeoffs, not just outcomes.
5. Avoid narrow platform assumptions unless they are explicitly called out as examples.

## Suggested contribution format

- problem
- context
- proposed pattern
- tradeoffs
- operational or governance considerations

## Pull request checklist

- documentation is updated
- examples remain anonymized and public-safe
- architecture tradeoffs are explained
- changes fit the repository scope
